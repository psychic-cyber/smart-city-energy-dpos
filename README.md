# ⚡ SmartGrid Energy Trading Platform

> **A Blockchain-Powered Smart City Energy Trading Platform**

SmartGrid is a decentralized **Peer-to-Peer (P2P) Energy Trading Platform** that enables households, businesses, and institutions to securely buy and sell surplus electricity using **Blockchain Technology**, **Ethereum Smart Contracts**, and the **Polygon Network**.

The platform combines **real-time energy monitoring**, **decentralized marketplace**, **DPoS consensus**, **AI-powered analytics**, and **blockchain transparency** to create a secure, scalable, and intelligent smart city energy ecosystem.

# 🚀 Installation

Clone the repository

```bash
git clone git@github.com:psychic-cyber/smart-city-energy-dpos.git
```

Navigate to the project

```bash
cd smart-city-energy-dpos
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate Environment

Windows

```bash
venv\Scripts\activate
```

Linux

```bash
source venv/bin/activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ⚙ Configuration

Create a `.env` file.

```env
SECRET_KEY=your_secret_key

RPC_URL=https://polygon-amoy.g.alchemy.com/v2/your_api_key

PRIVATE_KEY=your_private_key

CHAIN_ID=80002

CONTRACT_ADDRESS=your_contract_address
```

# 📜 Smart Contract Deployment

Compile Smart Contract

```bash
python compile.py
```

Deploy Smart Contract

```bash
python deploy.py
```

Initialize Smart Contract

```bash
python initialize.py
```

Deployment generates:

- Contract Address
- Transaction Hash
- Block Number
